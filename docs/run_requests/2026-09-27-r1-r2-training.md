## 5. Abort conditions (per run)

- Kernel fails any pre-training assert (dataset count, install) → fix, regenerate, re-push; no
  partial run is kept.
- `train/loss` is NaN or `val/loss` is NaN at any validation → run recorded as failed with its
  log; not silently restarted with a different recipe.
- Early stopping fires → normal completion; the epoch is recorded.
- Kaggle session ends before `last.ckpt` of epoch 50 or early stopping → run recorded as
  truncated; **not** a result; a resume decision is requested rather than improvised.
- The tiny run's `val/loss` after 10 epochs is not below its epoch-1 value → flag in chat before
  continuing to spend GPU quota (a sanity check, not a selection).
- Anything in the log that contradicts the manifest (commit, config SHA-256) → discard the output.
